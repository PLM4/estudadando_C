Conversão de string  

atof();  converte string para double  
atoi();  converte string para int  
atol();  converte string para long  

Geração de sequência pseudo-aleatória  

rand();  gera sequência pseudo-aleatória  
srand();  Inicializa o gerador de sequência pseudo-aleatória  

Gerenciamento de memória dinâmica  

malloc();  aloca memória dinâmica  
calloc();  aloca memória dinâmica e zera os bytes  
free();  libera memória dinâmica  
realloc();  reajusta memória dinâmica

Pesquisa e ordenação

qsort(); ordena os elementos em um array

Aritimética de inteiros

abs(); valor absoluto
div(); divisão inteira
